Frequently Asked Questions

Everything you need to know about Sponskip's operation and safety.

Is Sponskip free and safe to use? ▼

Sponskip is free to use and requests host permissions to inspect YouTube playback and fetch public SponsorBlock segment metadata. It does not require an account and includes no Sponskip analytics or tracking pixels.

How does Sponskip differ from regular ad blockers like uBlock Origin? ▼

Standard ad blockers block server requests for YouTube video ads and side banners. However, in-video creator sponsorships are baked into the video stream itself. Sponskip detects those segment timestamps and automatically advances the video playhead past them.

Does this require an external AI API key or remote server? ▼

No. Sponskip does not require an AI API key. It uses browser-side logic and public SponsorBlock segment data.

The listing is being prepared. In the meantime, users can install the current GitHub release with the ZIP steps above.
