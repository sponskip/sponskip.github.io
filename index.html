Frequently Asked Questions

Everything you need to know about Sponskip's operation and safety.

Is Sponskip free and safe to use? ▼

Yes. Sponskip is completely free, 100% client-side, and requests only the minimal host permissions required to inspect YouTube playback times and fetch segment metadata. No accounts, logins, or tracking pixels are ever used.

How does Sponskip differ from regular ad blockers like uBlock Origin? ▼

Standard ad blockers block server requests for YouTube video ads and side banners. However, in-video creator sponsorships are baked into the video stream itself. Sponskip detects those segment timestamps and automatically advances the video playhead past them.

Does this require an external AI API key or remote server? ▼

No. Sponskip requires zero OpenAI/Anthropic/Gemini API keys. It runs purely on local browser logic and crowdsourced SponsorBlock segment data.

When will Sponskip be live on the Chrome Web Store? ▼

The draft package has been assembled and is undergoing the standard Google Developer review process. In the meantime, users can install it instantly in 30 seconds via the verified GitHub ZIP package.
