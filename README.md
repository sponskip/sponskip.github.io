# Sponskip website

This repository publishes the static product site for Sponskip at [sponskip.com](https://sponskip.com/).

The extension source, releases, support, privacy implementation details, and source-available license live at [sponskip/sponskip](https://github.com/sponskip/sponskip).

## Site content rules

- Product claims must be traceable to the current extension source.
- Do not state that a Chrome Web Store listing is submitted, in review, approved, or available unless the corresponding dashboard state is real.
- Do not describe Sponskip as open source; it is source-available under its repository license.
- The public privacy policy must match the extension's current permissions, storage, and external requests.

## Local preview

Open `index.html` in a browser or serve this directory with any static HTTP server. The site has no build step.
