# Contributing to the Sponskip website

Keep website changes factual, accessible, and consistent with the extension repository.

- Verify every product claim against `https://github.com/sponskip/sponskip` before publishing it.
- Keep the privacy policy synchronized with extension permissions, browser storage, and third-party requests.
- Do not add analytics, trackers, or new network integrations without an explicit privacy review.
- Do not include credentials, private screenshots, account data, or unlisted video URLs.

Before opening a pull request, check both `index.html` and `privacy.html` for broken links and unsupported claims.
